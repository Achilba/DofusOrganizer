Team Organizer

Outil non officiel, sans lien avec Ankama. Il ne lit pas le jeu et n'envoie aucune donnee.

INSTALLER
Telecharge TeamOrganizer.exe sur la page des versions :
https://github.com/Achilba/Team-Organizer/releases/latest
Si Windows affiche "Windows a protege votre ordinateur" : Informations complementaires > Executer quand meme.

DONNEES
%AppData%\DofusTeamOrganizer\data.json  (+ Backups\ : une copie par jour, 7 gardees)
Journal d'erreurs : %AppData%\DofusTeamOrganizer\errors.log

COMPILER (pour les curieux)
Installe le SDK .NET 8, puis double-clique build.bat. Le resultat est dans le dossier "publish".
