# DOFUS Team Organizer

Petit logiciel Windows pour organiser une équipe de personnages dans Dofus : personnages et métiers, invitations de groupe, Zaaps favoris, Almanax, donjons et succès, songes (Cauchemar, Rêve, Para), tâches et notes, avec une barre « Mini » qui reste à côté du jeu.

> **Outil non officiel, sans lien avec Ankama.** Dofus est une marque d'Ankama. Cette appli ne lit pas le jeu, n'automatise aucune action et n'envoie aucune donnée : tout reste sur ton ordinateur.

## Installer
1. Ouvre la page des versions : https://github.com/Achilba/DofusOrganizer/releases/latest
2. Télécharge `DofusTeamOrganizer.exe` et lance-le. Rien d'autre à installer.
3. Windows peut afficher « Windows a protégé votre ordinateur » (l'appli n'est pas signée) : clique sur **Informations complémentaires**, puis **Exécuter quand même**.

L'appli propose elle-même les mises à jour (Paramètres → Mises à jour).

## Tes données
Elles sont dans `%AppData%\DofusTeamOrganizer` (fichier `data.json`, une sauvegarde par jour dans `Backups`). Paramètres → « Réinitialiser » remet l'appli comme à la première installation.

## Un problème ?
Paramètres → « Copier les infos pour le support », puis colle le texte dans une issue GitHub ou envoie-le à l'auteur.

Les données du jeu (Almanax, Zaaps, donjons, quêtes) sont saisies à la main et peuvent être en retard sur une mise à jour de Dofus. Le projet est en version 0.x : des défauts sont normaux.
